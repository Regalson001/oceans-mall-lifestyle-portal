
# Oceans Mall Umhlanga — Luxury Retail & Lifestyle Portal

A premium, responsive front-end showcase inspired by Oceans Mall in uMhlanga, KwaZulu-Natal, South Africa.

The project presents a modern luxury-shopping and visitor-information experience, combining coastal-inspired visuals, editorial typography, interactive components and responsive layouts.

## Live Demo

Coming soon — deploy with GitHub Pages.

## Preview

The experience includes:

- Cinematic hero section inspired by coastal architecture.
- Mall introduction and destination highlights.
- Platinum Walk luxury retail showcase.
- Fashion and lifestyle editorial cards.
- Coastal dining experience section.
- Visitor guide with trading-hours information.
- Location and directions integration.
- Parking and concierge information panels.
- Interactive FAQ accordion.
- Responsive mobile navigation.
- Scroll-triggered reveal animations.

## Technologies

- HTML5 — semantic page structure.
- CSS3 — responsive layouts, Grid, Flexbox and animations.
- JavaScript ES6+ — DOM interaction and interface functionality.
- Google Fonts — Playfair Display and DM Sans.
- Unsplash — illustrative photography.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Regalson001/oceans-mall-lifestyle-portal.git
   ```

2. Open the project folder:

   ```bash
   cd oceans-mall-lifestyle-portal
   ```

3. Open `index.html` in your browser.

4. For a better development workflow, open the folder in Visual Studio Code and use the Live Server extension.

## Design Features

- Coastal luxury visual identity.
- Navy, champagne-gold and warm ivory palette.
- Editorial serif typography.

## Customisation

Replace the illustrative photography with approved Oceans Mall photographs.

Verify store listings, trading hours, parking information, visitor services and contact details against the mall's official information before publishing factual visitor guidance.
